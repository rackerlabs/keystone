=====================
Extension Development
=====================

The files seen in keystone/contrib/example are meant to act as a guideline.

When adding a new extension to Keystone, please also:
    1. Add documentation on how to configure the extension by adding a new
    file under doc/source/extensions.

    2. Creating a new section in the doc/source/configuration.rst file for
    the new extension that references the newly added configuration
    documentation.
